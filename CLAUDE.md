# Ausie Trader AI - project notes

The standing brief in `~/.claude/CLAUDE.md` applies in full. This file records
only what differs, so a future session does not rebuild the Vite setup that was
removed on 2026-10-26.

## Stack

**Next.js 16 App Router**, static export. This project is a Next.js exception
to the "React + Vite" default in the global brief.

```
app/
  layout.jsx            root shell: fonts, metadata, header/footer, GA
  globals.css           the whole design system, one file
  page.jsx              home
  <route>/page.jsx      one directory per route
  not-found.jsx         becomes 404.html
src/
  components/           all UI, shared by the pages above
  data/                 content.js and seo.js
  lib/                  metadata mapping, lead submission
```

`next.config.mjs` sets `output: 'export'`, `trailingSlash: false` and
`images.unoptimized`. Routes build to `out/<route>.html`, which keeps the
canonical URLs identical to the entries in `sitemap.xml` (no trailing slash)
and lets Vercel serve `/about` from `about.html`. `out/404.html` gives an
unknown path a real 404 status.

Build with `npm run build`. The output is `out/`, not `dist/`; both are
gitignored.

## Rules that are easy to break here

- **`'use client'` is required** on anything with a hook. Currently: `Header`,
  `Logo`, `SignupForm`, `PhoneField`, `Faq`, `PreloadResources`. Adding a hook
  to a server component fails the build.
- **No event handlers on server components.**
- **Metadata comes from `src/lib/metadata.js`**, which maps `src/data/seo.js`
  onto Next's Metadata API. Do not hand-write head tags in a page.
- **Noindex routes carry no canonical.** `pageMetadata()` omits it when
  `canonical` is absent. `app/not-found.jsx` drops `robots` too, because Next
  injects its own and two tags end up in the HTML.
- **The 404 is `app/not-found.jsx` -> `out/404.html`.** Do not reintroduce an
  SPA rewrite in `vercel.json` or every unknown path returns the homepage at
  HTTP 200.
- **Homepage order:** Hero, TrustStrip, Why, Steps, Platform, Features,
  Showcase, RiskBand (`#risk`), FAQ teaser, LeadForm (`#register`), Cta. The
  risk band must stay above the form.
- **The OG image is `public/og-image.png` (1200x630).** `og-image.svg` is the
  source; regenerate the PNG if the SVG changes.
- **Platform and Showcase use the operator's transparent renders** from
  `public/images/` as 800w and 1200w WebP pairs. The original PNGs are in
  `design-assets/` and gitignored. Do not flatten them onto a background, add
  a frame, or add a caption: the operator supplied them transparent for the
  page.
- **The form is one component** (`SignupForm`) rendered on the homepage and
  `/contact`. Its ids (`firstName`, `lastName`, `email`, `phone`, `agree`,
  `company`) are selected by the audit harness and password managers.
- **`company` is a honeypot**, off screen and out of the tab order. Never send
  it in the payload.
- **`/how-it-works` and `/reviews` are extra routes.** The Reviews page shows
  the five reviews supplied by the operator. The operator confirmed they come
  from their own site, so reuse is authorized. Do not add extra testimonials,
  ratings or customer counts without real, permission-cleared reviews.
- **`AGENTS.md` at the repo root is generated by `next dev`.** Removing it only
  re-creates it; commit it with the rest of the work.
